# Seguridad

Este repositorio contiene documentación y presentación del proyecto. No incluye el código de la aplicación desplegada. Los cambios de documentación no corrigen vulnerabilidades de esa aplicación.

## Reportar un problema

Contactá a [Emanuel Duarte](https://github.com/em4nu3i69dll) por el medio de contacto indicado en su perfil. Compartí la versión afectada, el archivo o función y una reproducción mínima con datos ficticios.

No publiques tokens, contraseñas, cookies, bases de datos ni información personal en issues o capturas. Para problemas de dependencias, adjuntá el identificador del aviso y la versión instalada.
